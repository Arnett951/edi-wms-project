Figure 1 — Where the pieces live

One Container App revision runs two containers sharing a network namespace: the FastAPI app and a tailscale sidecar. That's what lets the app reach a GPU box on a home network it has no public route to — it dials localhost:1055, not the internet.

Operational notes

Cold start
minReplicas is 0. First request after idle waits on the whole replica (both containers) coming up before it's routed — tailscale has to re-auth too.
Local-model timeout
7s connect+read on each of the two Qwen calls. Fails fast to Claude rather than making the user wait on a slow GPU box.
Worker timeout headroom
gunicorn runs with --timeout 90 — enough for both AI tiers to fail in sequence without the worker getting killed mid-request.
Identity persistence
The sidecar's /tailscale-state lives on Azure Files, not container-local /tmp — so it resumes the same tailnet node instead of registering a new one on every restart.
Scope: request-time traffic for /api/chat only. Not shown: the ACR image build/push path, GitHub Actions, or the decommissioned App Service this replaced.
